最快接手
在已安装项目依赖、已切换到最新member4/augmentation-gsd分支的项目根目录执行：
  python scripts/download_member4_C.py --output runs/member4_C_release_20261116 --records
  python -m transparent_seg.predict --checkpoint runs/member4_C_release_20261116/best.pt --image runs/member4_C_release_20261116/records/demo/input.jpg --output runs/member4_C_release_demo --device auto
若用本项目Windows虚拟环境，把python替换为.\.venv\Scripts\python.exe即可。
查看runs/member4_C_release_demo/mask.png和overlay.png：分别为0/255分割图和绿色预测叠图。
输出尺寸应与示例原图一致，为444×613；加载时无需下载ImageNet权重，无需完整训练数据。
使用自己的RGB图片时，把--image改成自己的路径，--output改成尚不存在的新目录。
只想下载模型、不需要原始评分和示例图，可去掉第一条命令的--records。

新电脑
先取得本分支：
  git clone --branch member4/augmentation-gsd https://github.com/YUANJIAYI-UST/MAIE5421_Group24.git
  cd MAIE5421_Group24
再按项目README和scripts/setup.ps1准备依赖。正式环境为Python3.10.11、torch2.7.1+cu128、
transformers4.46.3、numpy2.2.6、Pillow11.3.0、scipy1.15.3。
仅做单图展示可用CPU（--device cpu）；正式分数复核应使用记录中的评估设置和兼容环境。
不同硬件的细小浮点差异不能用来推断模型文件有损坏；文件完整性以SHA256为准。
