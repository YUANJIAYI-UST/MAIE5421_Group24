审计命令：
  .\.venv\Scripts\python.exe -m transparent_seg.prepare --root data/Trans10K --output manifests/trans10k
若只导入小样本做 pilot，可用 --allow-partial；主 research 配置会拒绝不完整划分。
不要通过 --allow-partial 把缺数据的结果包装成完整 benchmark。

标签规则：RGB channel mean 0/85/255 -> binary 0/1/1。
红色 [255,0,0] 也有 mean 85；不能 convert('L') 再阈值。
白色 255 是前景，绝不是默认 ignore_index。未知颜色立即报错，由人确认。
当前官方 V1 路径无显式 void 配置；若版本有 void，必须注明来源并独立定义，不能吞掉未知值。

二、类别隔离：Trans10K-v2 —— 只用于细类别过滤/recall
官方代码与数据链接：https://github.com/xieenze/Trans2Seg
Google Drive：https://drive.google.com/file/d/1YzAAMY8xfL9BMTIDU-nFC3dcGbSIBPu5/view
百度：https://pan.baidu.com/s/1P-2l-Q2brbnwRd2kXi--Dg  提取码 oqms
官方结构中标签目录为 masks_12，含背景和 11 个前景细类别。
V2 与 V1 共用图像，不能把它当成独立外部测试集。
必须审计 V2 原始 palette/ID；本版不猜颜色映射，也未实现 V2 解码。
训练和二值评估保持 V1 GT；V2 只确定图像中是否出现 held-out 类及类别 recall。

三、跨数据集迁移：GSD (CVPR 2021)
作者项目：https://jiaying.link/cvpr2021-gsd/
当前作者项目页链接到：https://huggingface.co/datasets/garrying/GSD
只使用其 test split 对 A/D 做零微调迁移。不要混用 GSD-S 或 GDD。
下载时固定仓库 revision，保存 dataset card、文件清单、图片数及 mask 唯一值。
不要从二手论文的总图片数推断当前 release 的 split；以审计后的实际清单为准。
当前数据卡列出 CC BY-NC 4.0；实际使用时保存许可版本并按论文引用。
GSD 专用导入、Trans10K 重叠/近重复分析、标注兼容性与真实评估是成员 4/1 的后续任务。

五、数据使用与复现
数据和预训练权重许可分别保留；代码仓库许可不自动等于数据/权重许可。
GitHub 只保存代码/配置/汇总，不重新公开数据集原图、网盘归档或巨大权重。
在论文引用原作者。发布 checkpoint 前检查其适用许可和课程公开规则。
audit 的精确像素 hash 可发现跨 split 完全相同图，但不是完整近重复证明。
正式结果应记录 archive SHA256、manifest SHA256、排除清单和审计者。
