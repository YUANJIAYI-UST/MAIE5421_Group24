一、老师的明确要求
R01 RGB 输入、透明区域二值输出。
  对应：predict.py，输出 mask.png 和 overlay.png；尺寸与输入相同。
  验收：真实玻璃器皿/瓶/窗图片逐一检查；mask 只有 0 和 255。
  状态：接口已实现；真实效果未验证。
R02 不同透明材质与复杂背景。
  对应：官方 Trans10K 全集和 easy/hard 分组。
  验收：full test + hard test 表，并展示窗、杯、瓶、杂乱背景、反射与遮挡。
  状态：数据管道和分组评分已实现；正式实验待执行。
R03 benchmark 定量指标、定性视觉分析。
  对应：pooled foreground IoU / region F1(Dice) / per-image CSV / 四联图。
  验收：固定 test 清单、选定 checkpoint、可复现命令、好坏案例均报告。
  状态：评估入口已实现；无 benchmark 分数。
R04 边界定位。
  对应：辅助边界监督、原尺寸 Boundary IoU；B 对 A、D 对 C 的配对比较。
  验收：边缘局部放大图，量化边界改善是否以区域 IoU 为代价。
  状态：算法与指标已实现并有测试；真实收益待验证。
R05 背景与照明鲁棒性。
  对应：hard 子集 + 12 个受控亮度/对比度/gamma 条件。
  验收：各条件绝对得分、均值、clean-to-perturbed drop。
  限制：光度变换不模拟物理折射；改变背景的泛化还需真实 hard/GSD 案例支撑。
R06 对未见类别的泛化（Topic 10 Critical Considerations）。
  对应：proposal 的 V2 类别隔离实验；普通随机划分不足以证明未见类别泛化。
  状态：实验设计已写入任务，自动 V2 映射/过滤/类别 recall 尚待实现。

五、冲高质量的验收门槛（组内标准，不是老师公布的数值评分线）
1) 软件测试全通过；小样本可以过拟合，且排除全背景塌缩。
2) official split 的 count/hash/编码、异常/重复处理都有文件证据。
3) 四组只改变预先约定的变量，训练时长/预算相同；测试集不参与超参选择。
4) 主表、边界表、扰动表、迁移表、未见类别表有可复现来源；缺项标明。
5) 关键比较尽量 A/D 三种子，报告均值和标准差，不只选择最好的 seed。
6) 包含失败案例、局限、负结果；不拿二值前景 IoU 对比论文 multiclass mIoU。
7) 五人贡献、里程碑、引用完整；他人干净环境能按 README 运行。
8) 不预设“方法一定提高”：若 D 不优，分析边界权重、负迁移与误差类型。

老师没有公布具体得分权重或最低 IoU/F1 阈值，因此本文件不能换算保证成绩。
