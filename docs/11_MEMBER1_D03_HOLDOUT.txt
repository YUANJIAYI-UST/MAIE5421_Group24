1. 这项工作做了什么
V1 负责“透明／不透明”的二值标签；V2 只告诉我们图片里有哪些细类别。
先从训练／验证数据选出两类，再把包含它们的整张图片从训练和验证中移除。
训练后的模型用官方测试集中含这两类的图片检验泛化能力。
“未见”只指本任务的训练数据；不声称 ImageNet 预训练没有见过这些语义类别。

3. 对齐与编码审计
官方 split 的 5000 train／1000 validation／4428 test 文件名全部一一对应。
V2 有缩放和重新压缩，故不要求 V1/V2 的 JPEG 文件 SHA 相等。
先核对同 split、原文件名，再比较长宽比、96x96 RGB 图像与 pHash。
18 张旋转图片沿用 D01 的明确记录（16 顺时针、2 逆时针），把 V2 图像方向
变换到 V1 坐标系后比较。只记录变换，不改写原 V1/V2 文件。
10428 对均通过：最大相对长宽比差 0.001070 以内；缩略图 RMSE 最大 0.813；
pHash 汉明距离最大 4。图像内容一致是这些检查支持的结论，不等于所有语义标注正确。
全部 V2 mask 使用精确作者 RGB palette 解码；本镜像无未知颜色、缺失或无法对齐条目。
代码也支持显式的原始 P/L 索引编码；不能把 RGB 图任意 convert('P') 后猜 ID。
上游类别名 Floor Glass（ID 8）在论文中称 glass wall；Glass Bow（ID 9）
在论文中为 glass bowl。保留代码原名和 ID，不偷偷重排 ID。
论文：https://www.ijcai.org/proceedings/2021/0165.pdf

4. 选类规则与真实计数
规则文件：configs/data/trans10k_d03_rules_20261028.json
选类只使用 D01 派生基础中的 train 4990／validation 999，不使用 test 类别统计。
每个候选类别至少有 50 张训练、10 张验证；移除两类后两个 split 都至少保留 60%，
且其余九类仍在训练和验证中出现。按“两类中较少的验证图片数”最大优先；
依次以较少训练数、剩余训练数、剩余验证数、升序 ID 打破平局。
完整候选组合、淘汰原因、类别图片数和像素数均保存在 selection/ 中。

5. 文件入口
transparent_seg/data_v2.py：明确类别解码，不接管 V1 二值标签。
transparent_seg/prepare_holdout.py：先 select 后 build，测试审计必须引用已冻结选择。
scripts/audit_trans10k_v2.py：V2 导入、图像对齐、编码与类别计数。
scripts/verify_holdout_release.py：直接读取真实标签，独立检查隔离和复现。
tests/test_holdout_data.py：混合类别移除、测试隔离、V1 保留、篡改拒绝等测试。
manifests/trans10k_d03_20261028/：5 个 manifest、audit.json、类别计数、排除理由、release.json。
runs/trans10k_d03_20261028/selection/：只含 train/validation 的选类依据。
runs/trans10k_d03_20261028/{train_val_aligned,test}/：全部逐图 V1/V2 对应与哈希。
runs/trans10k_d03_20261028/human_review/：两类抽样图、18 张旋转对比、人工确认空表。
runs/trans10k_d03_20261028/verification.json：最终真实数据检查结果。

V1 manifest 中 image/mask 路径、hash、binary encoding 和 D01 mask_transform 都保留。
V2 category mask 只作为额外字段，绝不将 V1 的 0/85/255 二值语义改成 V2 的类别含义。
V2 原生分辨率的像素数不能与 V1 原分辨率像素数直接比较。
如成员 5 计算类别 recall，应明确 V2 原生坐标系／v2_to_v1_orientation，
在 V2 GT 的坐标系对齐预测再算 TP/GT；不要直接把不同尺寸的两个数组逐像素比较。
二值 IoU/F1/Boundary IoU 仍对原尺寸 V1 GT 计算。类别 recall 聚合是成员 5 后续评估工作。

6. 可复现命令（Mac，在仓库根目录，输出目录必须不存在）
先完成 docs/10_MEMBER1_LOCAL_RELEASE.txt 的 V1 基础数据准备。
  .venv/bin/python -m pip install -r requirements-data.txt
  .venv/bin/python scripts/download_v2_mirror.py --split train validation
  .venv/bin/python scripts/audit_trans10k_v2.py --split train validation --output runs/trans10k_d03_20261028/train_val_aligned
  .venv/bin/python -m transparent_seg.prepare_holdout select --base manifests/trans10k_v1_review_20261028 --inventory runs/trans10k_d03_20261028/train_val_aligned/inventory.json --rules configs/data/trans10k_d03_rules_20261028.json --output runs/trans10k_d03_20261028/selection
冻结 selection.json 后再进行：
  .venv/bin/python scripts/download_v2_mirror.py --split test
  .venv/bin/python scripts/audit_trans10k_v2.py --split test --selection runs/trans10k_d03_20261028/selection/selection.json --output runs/trans10k_d03_20261028/test
  .venv/bin/python -m transparent_seg.prepare_holdout build --base manifests/trans10k_v1_review_20261028 --inventory runs/trans10k_d03_20261028/train_val_aligned/inventory.json --test-inventory runs/trans10k_d03_20261028/test/inventory.json --selection runs/trans10k_d03_20261028/selection/selection.json --rules configs/data/trans10k_d03_rules_20261028.json --output manifests/trans10k_d03_20261028
  .venv/bin/python -m pytest -q -W error
  .venv/bin/python scripts/verify_holdout_release.py --manifests manifests/trans10k_d03_20261028 --base manifests/trans10k_v1_review_20261028 --output runs/holdout_verified_new.json

同机复现：将 build 的 --output 换成同层的新目录，再把该目录作为 verifier 的 --reproduced。
检查全部 11 个交付 JSON 逐字节一致。保持目录层级、Python/Pillow/NumPy 版本相同。
