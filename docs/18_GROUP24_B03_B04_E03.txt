Main B/D
Use the frozen configs/group24_b03_{B,D}_seed42.json settings. B uses the boundary head;
D adds the same photometric augmentation as C. Both use full 4,959/995 reviewed V1,
batch 8, seed 42, 30 epochs and 18,600 updates. Select strictly on full original-size
validation IoU before evaluating the common 4,428-image clean test. Match common
ImageNet revision, initialization hash, BF16 training and other controls to A/C.

Isolated E03 A/D
Use configs/group24_e03_{A,D}_seed42.json with the frozen 3,230/646 D03 split.
Verify masks with scripts/verify_holdout_release.py and build separate train and
validation caches with transparent_seg.cache. Both models start from ImageNet plus
the same seeded decoder, use 30 epochs and 12,120 updates, and select on D03 validation.
The 4,428 test images partition into 2,935 seen and 1,493 held-out images. Report
V1 original-resolution region/Boundary IoU and background FPR, plus V2 native-frame
recall including class 5 Glass Door and class 8 Floor Glass.

Entry points (PowerShell, project root)
  .\scripts\run_group24_followup.ps1 -Stage B03_B
  .\scripts\run_group24_followup.ps1 -Stage B03_D
  .\scripts\run_group24_followup.ps1 -Stage E03_A
  .\scripts\run_group24_followup.ps1 -Stage E03_D

Training uses the pinned project environment and cached MiT-B0 weights. See docs/17
for setup and the V1 cache instructions; replace the V1 manifest/cache path with
its D03 counterpart when building the isolated cache. Use a new -RunRoot for
reproduction. Use -EvaluateOnly to recover an interrupted evaluation with the same
checkpoint, data, code and runtime. Default boundary morphology is SciPy. The
optional -EvalDeps path supplies OpenCV from a separate dependency directory.

The B04 summary takes member 4's published condition_results.csv and compares
B−A and D−C on all/easy/hard, with the boundary × augmentation interaction.
The fixed visual examples show thin spectacle lenses, furniture occlusion and a
large shop window. The clean-test study reports single-seed effects; C ran on a
different GPU/Python environment. Run the summary and rendering scripts after
both checkpoint evaluations complete. E03 has separate comparison and recall tables.
